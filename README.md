# Landing Page

This is a responsive landing page created as part of my Web Development Internship task.

The project focuses on creating a clean and user-friendly interface using HTML, CSS, and JavaScript.

## Features

- Responsive navigation bar
- Hero section
- Courses section
- Features section
- About section
- Statistics counter
- Student testimonials
- Pricing section
- FAQ accordion
- Call to action section
- Dark and Light mode
- Responsive design for mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

While working on this project, I learned how to create responsive layouts using CSS Flexbox and Grid. I also practiced JavaScript DOM manipulation, event handling, dark mode, counters, and interactive FAQ functionality.
